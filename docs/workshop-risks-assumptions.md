# Workshop Risks and Assumptions

## Risks
- Inconsistent metric definitions across teams delay sign-off.
- Missing historical data limits target accuracy.
- Security SLA definitions differ by product line.
- Tool API limits affect refresh cadence.

## Assumptions
- Leadership accepts MVP with 15-20 KPIs.
- Jira/SonarQube/Snyk/CI-CD access is available in Week 1.
- Each KPI will have a named owner by end of Day 2.

## Mitigations
- Use a single KPI dictionary as source of truth.
- Capture exceptions explicitly in `exclusions` column.
- Tag deferred items as Wave 2 with owner and due date.
